Neighborhood

Solana Launchpad for vetted crypto projects

Neighborhood vets founders, enforces KYC, and uses board + governance approvals before any token sale goes live. Built for Solana speed with launch controls for vesting, refunds, and liquidity handling, presented in a retro terminal-inspired interface.

Solana-native KYC + Board Review DAO Governance Liquidity Locking

Project Vetting Submission

Vetting Pipeline

  1. Step 1: Application received
  2. Step 2: KYC + identity checks completed
  3. Step 3: Technical and tokenomics review board decision
  4. Step 4: Governance vote for listing approval
  5. Step 5: Launch setup (sale contract, vesting, refunds, LP locks)
